## The word

**Talkie**

The single word my grandma would text about AI. "Talkie" is the word from
her own era for a thing that talks — she grew up with the talkies, and now
she meets a machine that talks back. So she reaches for the only word she
has for it: warm, a little baffled, and exactly what she would type to a
grandchild.

## How it works

`main.ts` writes exactly one word, `Talkie`, to `/output/entry.txt`. No
network, no environment reads, no dependencies — just the word.

```sh
node main.ts
cat /output/entry.txt
# Talkie
```
